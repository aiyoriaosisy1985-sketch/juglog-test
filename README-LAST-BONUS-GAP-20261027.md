# 最終BB・RBからの経過ゲーム数（候補版）

- 実戦タブの累計確率欄直下に2項目を追加。確率ではなく経過G。
- P31の確定済みイベント順と GAMES_RECORDED の増分から集計。保存処理には非接続。
- BB当選時はBBが0G、RB当選時はRBが0G。現在のゲーム数追加に追従。
- 有効な同種ボーナスが一度もない場合は「—」。
- 保留未確認ボーナスは加えず、確認済みなら当選時の位置に反映。
- P31の本人Gとイベント増分合計が異なる場合は安全上「—」。
- Undo・訂正・実戦切替はP31スナップショットの再計算に追従。
- 開発者固定テストのみ。iPhone実機は未検証。GitHub未反映。
