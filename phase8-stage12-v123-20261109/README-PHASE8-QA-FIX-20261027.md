# Phase 8｜実機検証後の限定修正候補（2026-10-27）

## 今回反映した変更
- D07F 収支／カード記録の確認ダイアログで、内部イベント識別子を日本語ラベルに変換。イベント識別子自体・保存内容・P31保存処理には手を加えていない。
- D07Fのカード欄で、初期残高が未登録の場合は「残高未確認（初期残高未登録）」と表示。入庫100枚だけからカード残高100枚だとは断定しない。
- D07Fの関係する入力欄のフォントを16px以上にして、iPhone Safariによる入力時自動ズームを回避（一般のピンチズームは禁止しない）。

## コード調査の結果／今回触らない箇所
- card-engine.js は初回残高実測まで knownBalance=null とする仕様。CARD_DEPOSIT は履歴に残り、残高実測がない場合に残高が未確認なのは設計どおり。
- phase8-net-graph.js は実測点のゲーム数に比例するX座標で配置済み。以前の「有効イベント順」という文言は別のBB/RB累積図の説明で、差枚図の軸ではない。従って差枚グラフの軸を誤って修正しない。
- 再読み込み時の実戦選択が一時的に未選択となる件は再現原因が不確定。P31選択が保持されていたため、lease/保存/選択の中核コードへの推測修正は行わない。
- ホール累計の同値保存では永続性の独立検証ができない。追加試験が必要なら計画して行う。
